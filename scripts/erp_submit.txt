# ====================================================
#  示例脚本：ERP 自动保存并提交审核
#  用法：在 controller.exe 里输入 run erp_submit.txt
# ====================================================

# 第一步：查看控件树（第一次调试时用，确认控件名称）
# tree|ERP系统|5

# 第二步：点击工具栏"保存"按钮（在工具栏父容器内精确查找）
click|ERP系统|保存|工具栏

# 等待500毫秒，给程序处理时间
sleep 500

# 第三步：等待"保存成功"弹窗，自动点确定
wait|ERP系统|保存成功|confirm

# 等待一秒
sleep 1000

# 第四步：点击"提交审核"按钮
click|ERP系统|提交审核

# 第五步：等待审核确认弹窗
wait|ERP系统|确认提交|confirm

# 第六步：等待"提交成功"提示
wait|ERP系统|提交成功|confirm

# 完成
